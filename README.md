# BasalGanglia_ACh_PDD_model
Computational modelling of acetylcholine deficiency-mediated dysfunction in the basal ganglia-thalamocortical network related to Parkinson's disease dementia

Manuscript ID: PONE-D-26-10605R2, PLOS ONE

This repository contains all MATLAB simulation code used to reproduce the results and figures in the manuscript.

## Environment
- Software: MATLAB R2019b (or newer)

## How to run
1. Download all .m files to your local folder
2. Open MATLAB and set this folder as working directory
3. Run main_Euler.m or main_RK4.m for different integration schemes
4. Adjust acetylcholine deficiency parameters inside script files
5. Simulation outputs and figures will be generated automatically
